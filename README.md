# 🛕 PujaConnect

PujaConnect is a digital platform that enables users to discover, compare, and book verified Pandits for religious ceremonies such as Satyanarayan Katha, Naamkaran, Griha Pravesh, Havan, Mundan, and other rituals. The platform supports both home-based and temple-based puja services with transparent pricing, booking management, and detailed ritual information.

## ✨ Features

- Verified Pandit listings
- Online booking system
- Home & temple puja services
- Transparent pricing
- User authentication & authorization
- Pandit dashboard
- User dashboard
- Booking management
- Responsive UI
- Chat support integration

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### Other Tools
- Cloudinary
- JWT Authentication

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/TheREAl1legend/PujaConnect.git
```

Move into the project folder:

```bash
cd PujaConnect
```

Install backend dependencies:

```bash
cd backend
npm install
```

Install frontend dependencies:

```bash
cd frontend
npm install
```

## ▶️ Run the Project

Start backend server:

```bash
cd backend
npm run dev
```

Start frontend:

```bash
cd frontend
npm run dev
```

## 🔐 Environment Variables

Create a `.env` file inside the backend folder and add:

```env
PORT=5000
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_secret_key
CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret
```
